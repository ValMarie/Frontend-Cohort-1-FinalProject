# My Movies Tracker

A personal movie watchlist app built with React and the TMDB API. Search for movies, add them to your watchlist, mark them as watched, and filter your collection.

## Setup

1. Clone this repository
2. Install dependencies:
   ```
   npm install
   ```
3. Create a `.env` file in the root directory (use `.env.example` as a template):
   ```
   VITE_TMDB_API_KEY=your_api_key_here
   ```
   Get your free API key at https://www.themoviedb.org/settings/api
4. Start the development server:
   ```
   npm run dev
   ```

## Features

- Search movies using the TMDB API
- Add movies to your personal watchlist
- Mark movies as watched/unwatched
- Filter your watchlist (all, watched, unwatched)
- Watchlist persists in localStorage

## Tech Stack

- React (Vite)
- TMDB API
- CSS (no frameworks)
- localStorage for persistence
